WebSquare DataCollection Generator

명세서에서 복사한 텍스트(3줄 = ID / DataType / 한글명) 또는 Java DTO 선언문으로 w2:dataMap / w2:dataList XML 을 생성합니다.

입력

dma_
최종 ID: dma_
DTO 모드에서 ID 를 비워 두면 클래스명에서 자동 생성합니다. (예: DisclsReviewListResponseDto → disclsReviewList)
기본은 hidden = true 필드를 제외합니다. 체크하면 hidden 필드도 생성에 포함합니다.

NUMBER·INT·INTEGER·FLOAT·DOUBLE·NUMERIC  → number

TIME                                     → time

DTO 선언문 파싱 규칙

id   : 필드명 그대로                       (예: applNo)
name : @Schema(description|title) → @ApiModelProperty(value)
       → 필드 위 주석(/** */ · //) → 빈값
hidden : @Schema(hidden = true) / @ApiModelProperty(hidden = true)
         → 기본 제외, "hidden 컬럼 포함" 체크 시 포함
