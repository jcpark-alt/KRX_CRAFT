편집기 호출(모달)

타입이름설명
stringparam[Query Parameter]
- formCd (필수)
값 : 서식코드 (예: 91370)
설명 : 진입할 서식(본문서식) 코드. entryTpCd=AS/CR일 때는 원문서의 본문서식 코드(disclsMaindocFormCd)
- entryTpCd (필수)
값 : NK | NE | CR | AS | QA
설명 : NK = 새문서 작성(국문) / NE = 새문서 작성(영문) / CR = 정정문서 작성 / AS = 첨부문서 추가 / QA = 조회공시/해명요구 답변작성
- lang (필수)
값 : 0 | 1
설명 : 언어구분코드 (0: 국문, 1: 영문)
- formVer (entryTpCd=CR/AS이면 필수, 그 외는 선택)
값 : 서식버전
설명 : 특정 버전의 서식을 띄워야 할 때 사용. 미지정 시 최신 버전으로 조회.
entryTpCd=AS일 때는 원문서의 서식버전(disclsMaindocFormVer)을 그대로 사용
entryTpCd=CR일 때는 최신 또는 이전 버전 중 선택된 값 (-> 사용자가 정정 시 버전을 선택할 수 있으므로 원문서 버전과 다를 수 있음)
- applNo (선택)
값 : 신청번호
설명 : 임시저장된 문서를 불러와야 할 때 사용(임시보관함 재개). 지정하면 해당 신청번호의 저장 데이터를 불러와 화면에 세팅.
미지정 시 신규 작성으로 시작합니다.
- targetFormCd (선택)
값 : 서식코드
설명 : applNo와 함께 넘기면(임시보관함 재개) 진입 직후 화면에 가장 먼저 열어야 할 서식(본문 또는 첨부) 코드로 사용됩니다.
미지정 시 첫 번째 서식(본문)으로 이동합니다. (단, entryTpCd=AS이거나 CR+첨부정정이어서 본문 클릭이 차단되는 경우엔
본문 대신 첫 번째 첨부서식으로 대체됩니다)

[Query Parameter - entryTpCd=NK/NE/QA 전용]
아래는 applNo 없이 처음 진입하는 경우(아직 저장한 적 없는 신규 작성)에만 필요합니다.
정정문서(CR), 첨부추가(AS) 신규작성의 경우엔 필요없습니다. (원문서 정보를 복사할 예정)
- tgtIsurCd (필수, 신규 진입 시)
값 : 공시대상법인발행기관코드

- tgtFssUnqNo (선택, 신규 진입 시)
값 : 공시대상법인금감원고유번호

- tgtIsuSrtCd (선택, 신규 진입 시)
값 : 공시대상대표종목단축코드

[Query Parameter - entryTpCd=AS 전용]
- acptNo (필수 - 신규 진입 시)
값 : 원문서(공시완료건) 접수번호
설명 : 어느 완료 공시 건에 첨부서식을 추가하는지 식별하는 키. acptNo 값 기준으로 목차를 구성합니다.
- asTargetFormCd (필수, 신규 진입 시)
값 : 작성할 첨부서식(subdoc) formCd
설명 : 진입 직후 자동으로 이 서식으로 이동함
- targetFormCd (임시보관함 첨부문서 선택 시 필수)
값 : 작성할 첨부서식(subdoc) formCd
- addOrgnDisclsAcptNo (필수, 신규 진입 시)
값 : 추가원공시접수번호
설명 : AS-IS 기준 modOrgnDisclsAcptNo(정정원공시접수번호) 값을 그대로 사용
- inqOrgnDisclsAcptNo (필수, 신규 진입 시)
값 : 조회원공시접수번호
설명 : acptNo와 다르면 저장 시 disclsModAddTpCd가 'A'(추가공시) 대신 'Q'(조회공시의 정정)로 처리됨
- engOrgnDisclsAcptNo (선택, 신규 진입 시)
값 : 영문원공시접수번호

[Query Parameter - entryTpCd=CR 전용]
아래 4개(engOrgnDisclsAcptNo, modAddSeq 제외)는 applNo 없이 처음 진입하는 경우(아직 저장한 적 없는 신규 작성)에만 필요합니다. 빠지면 "잘못된 진입 정보입니다" 에러로 처리됩니다.

- acptNo (필수, 신규 진입 시)
값 : 정정 대상 원문서(공시완료건) 접수번호
설명 : 어느 완료 공시 건을 정정하는지 식별하는 키.
acptNo 값 기준으로 원공시접수번호를 조회하고, 원공시접수번호를 기준으로 서식코드별 최신 제출건으로 목차를 구성합니다.

- crTargetFormCdList (필수, 신규 진입 시)
값 : 정정할 서식코드 목록 (콤마로 구분, 예: 91370,99999)
설명 : 정정 대상으로 미리 선택한 서식(본문/첨부, 1개 이상).
목록에 formCd(본문서식코드)가 포함되지 않으면 첨부정정(U)으로 처리되어 진입 직후 목록의 첫 서식으로 자동 이동하며 본문 클릭이 차단됩니다.
- modOrgnDisclsAcptNo (필수, 신규 진입 시)
값 : 정정원공시접수번호
- inqOrgnDisclsAcptNo (필수, 신규 진입 시)
값 : 조회원공시접수번호
- engOrgnDisclsAcptNo (선택, 신규 진입 시)
값 : 영문원공시접수번호
- modAddSeq (선택, 신규 진입 시)
값 : 정정추가일련번호

업무 공통 함수(fil) $c.fil

fil 업무 모듈의 업무공통(KRX 고유) 함수를 작성한다. 단순 문자열/날짜/검증 함수는 gcc($c.str/$c.date/$c.util)를 직접 사용하고 본 파일에는 두지 않는다. 함수명은 camelCase 로 표준화하고 JSDoc 에 AS-IS 원본명을 병기한다.

fil.xml · 2개 메서드

$c.fil.checkMaxLength(obj, size, lbl)

컴포넌트 입력값의 byte 길이가 최대 길이(size)를 초과하는지 검사한다.
초과 시 초과 byte 수를 알림으로 표시하고 해당 컴포넌트로 포커스를 이동한다.
(AS-IS: checkMaxLength, origin: stf.xml)
AS-IS 의 getStringSize/getObjectValue → $c.str.getByteLength(한글 2byte 동일 규약)/컴포넌트 getValue 로 교체.

타입이름설명
Objectobj검사할 입력 컴포넌트 (getValue/focus 지원)
Numbersize최대 입력 byte 수
Stringlbl알림에 표시할 항목명

반환 Boolean 최대 길이 이내이면 true, 초과하면 false

if (!$c.fil.checkMaxLength(ibx_isuNm, 100, "종목명")) { return; }

$c.fil.setFromToDate(pTp, pObjFrom, pObjTo)

기간구분(pTp: 1주일/1·3·6개월/1·2년)에 따라 From/To 일자 컴포넌트를 자동 설정한다.
To 값이 비어있으면 서버 현재일(yyyyMMdd) 기준으로 계산한다.
(AS-IS: fn_setFromToDate, origin: stf.xml)

타입이름설명
Number|StringpTp기간구분 (1:1주일, 2:1개월, 3:3개월, 4:6개월, 5:1년, 6:2년)
ObjectpObjFromFrom 일자 컴포넌트
ObjectpObjToTo 일자 컴포넌트

반환 void 

$c.fil.setFromToDate(1, cal_fromDd, cal_toDd);
