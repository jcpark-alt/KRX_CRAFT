1개 모듈 · 8개 공개 메서드

분석/트래킹 공통 함수(trk) $c.trk

ins 모듈에서 분리한 분석/트래킹(외부 분석 솔루션 연동) 공통 함수. AS-IS _trk_* (origin: logger_tracking.xml). 트래킹 상태/이미지 객체(_trk_code_base, _trk_img_* 등)는 외부 트래킹 init 에서 주입되어야 동작한다.

trk.xml · 8개 메서드

$c.trk.trkEscape(_str)

트래킹 전송용 문자열 escape (특수문자 %인코딩).
(AS-IS: _trk_escape, origin: logger_tracking.xml)

타입이름설명
String_str원본 문자열

반환 String escape 된 문자열

$c.trk.trkSetCookie(name, value, expire)

트래킹용 쿠키를 설정한다. (path=/, expire 는 ms 단위 가산)
(AS-IS: _trk_setCookie, origin: logger_tracking.xml)

타입이름설명
Stringname쿠키 이름
Stringvalue쿠키 값
Numberexpire만료(현재시각 + expire ms)

반환 void

$c.trk.trkMakeCode(_TRK_SERVER, _TRK_U)

트래킹 호출 URL(tracker.jsp 파라미터)을 생성한다. 페이지/리퍼러/광고키/환경정보 포함.
(AS-IS: _trk_make_code, origin: logger_tracking.xml)

타입이름설명

String_TRK_U트래킹 사용자/서비스 코드

반환 String 트래킹 호출 URL (file:// 페이지면 "")
