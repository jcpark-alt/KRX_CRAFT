        문의 주신 경로의 이미지는 AS-IS 이미지 경로로 전환 프로젝트에는 존재하지 않는 이미지 파일입니다.

답변 : API 서비스는 신규로 작업 진행되고 있고 해당 정보는 전달이 불가하기 때문에 기존 API를 기반으로 전환이 되어야 합니다.

C. 서비스 prod base_url 확인
답변 : 현재 prod 경로는 존재하지 않습니다.

답변 : 코드목록도 프로젝트마다 호출하는 API가 다르지만, 기본 코드 API 경로는 "/api/common/common-code" 를 사용합니다.
	수정된 $c.data.setCommonCode 공통함수를 참고하시면 됩니다.

G. 작업본·셸 자체 의심 결함
답변 : 기본 접근 페이지를 index.html 파일을 사용하면 websquare.html 파일로 접근하지 않습니다.. (http://localhost/index.html 또는 http://localhost)
	정상 분기 HOME_EX_URL(/cm/main/fill/index.xml) 경로가 맞습니다.
	팝업 : 단순 조회나 코드 선택은 pageFramePopup 모드로 입력/수정/삭제/상세 등 업무 관련 화면은 browserPopup 형태로 사용이 됩니다.
