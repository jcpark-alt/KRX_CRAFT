iframe 내부 페이지에서 부모 팝업 창을 닫는 처리 흐름

작성 2026-09-16 · WebSquare 팝업(XML) 안의 iframe 페이지 → postMessage → 팝업 XML 이 $c.win.closePopup(result) 로 자기 팝업을 닫고 결과를 호출 화면에 반환 · 샘플 SMPIFR10000(호출) / SMPIFR10001(팝업) / resources/sample/iframe-popup-close-sample.html(iframe 페이지)

1. 전체 연동 흐름 요약

[0. 호출 화면 XML — SMPIFR10000]
   │
   └─ const result = await $c.win.openPopup("/ui/sample/template/SMPIFR10001.xml", options, param)
      (팝업이 닫힐 때 closePopup 에 실린 값이 result 로 돌아온다. 취소·자체 닫기는 undefined)

[1. 팝업 XML (Parent Window) — SMPIFR10001]
   │
   ├─ onpageload : $c.win.getPopupId() 로 popupId 획득
   ├─             iframe src URL 뒤에 ?popupId={popupId}(+ 호출 파라미터) 전달
   ├─             window 'message' 리스너 등록 (핸들러는 scwin.onIframeMessage 에 보관)
   └─ onpageunload : 같은 참조로 리스너 해제 (SPA 라 window 가 유지되므로 필수)

[2. iframe 내부 페이지 (Child Window) — iframe-popup-close-sample.html]
   │
   ├─ URL 쿼리 파라미터에서 popupId 추출
   └─ [확인]/[취소] 클릭 시 sendPopupMessage() → window.parent.postMessage({ execution, popupId, result })

[3. 팝업 XML (Parent Window)]
   │
   └─ 수신 필터 출처 → 형태 → execution → popupId 통과 시 $c.win.closePopup(result) 실행하여 팝업 종료

2. 단계별 상세 코드 정리

1팝업 XML (부모 창) — SMPIFR10001.xml

iframe을 포함하는 팝업 화면에서 popupId를 구해 iframe URL에 붙이고, iframe 페이지가 보내는 메시지를 수신하도록 설정합니다. 리스너는 onpageload 에서 등록하고 onpageunload 에서 반드시 해제합니다.

///////// 1. 변수 및 선언 영역 /////////
scwin.IFRAME_URL     = "/resources/sample/iframe-popup-close-sample.html";
scwin.ALLOWED_ORIGIN = location.origin;   // iframe 페이지가 같은 출처. 다른 도메인이면 그 출처로 고정
scwin.popupId        = "";

///////// 2. 초기화 영역 /////////
scwin.onpageload = async function () {
    try {
        await scwin.init();
    } catch (ex) {
        await $c.exception.handleError(ex, { context : "SMPIFR10001.onpageload" });
    }
};

scwin.onpageunload = function () {
    try {
        window.removeEventListener("message", scwin.onIframeMessage);   // 등록과 같은 참조여야 해제된다
    } catch (ex) {
        $c.exception.handleError(ex, { context : "SMPIFR10001.onpageunload" });
    }
};

scwin.init = async function () {
    scwin.popupId = $c.win.getPopupId();                                // 1. 팝업 ID 획득

    const param = $c.data.getParameter("pData") ?? {};                  // 호출 화면 파라미터(있으면 iframe 쿼리로 전달)

    // 2. iframe URL 에 popupId 전달 — w2:tag(iframe) 의 DOM 요소 id 는 컴포넌트 id 와 같다
    document.getElementById(ifr_page.getID()).src = scwin.buildIframeUrl(param);

    // 3. postMessage 수신 리스너 등록
    window.addEventListener("message", scwin.onIframeMessage);
};

///////// 3. 컴포넌트 이벤트 영역 /////////
scwin.onIframeMessage = function (event) {
    try {
        if (event.origin !== scwin.ALLOWED_ORIGIN) return;              // ① 출처
        const data = event.data;
        if (!data || typeof data !== "object") return;                  // ② 형태 (문자열·엔진 메시지 방어)
        if (data.execution !== "closePopup") return;                    // ③ 우리 규약 (엔진의 {_wq_type} 배제)
        if (data.popupId !== scwin.popupId) return;                     // ④ 다른 팝업의 iframe 메시지 무시

        $c.win.closePopup(data.result);   // 자기 팝업을 닫고 result 를 호출 화면의 await 결과로 돌려준다
    } catch (ex) {
        $c.exception.handleError(ex, { context : "SMPIFR10001.onIframeMessage" });
    }
};

///////// 5. 일반/업무 함수 영역 /////////
scwin.buildIframeUrl = function (param) {
    const query = new URLSearchParams();
    query.set("popupId", scwin.popupId);
    Object.keys(param || {}).forEach(function (key) {
        if (typeof param[key] === "string" || typeof param[key] === "number") query.set(key, String(param[key]));
    });
    return scwin.IFRAME_URL + "?" + query.toString();
};

closePopup 시그니처 주의 — $c.win.closePopup(callbackParam, callbackFnStr) 는 호출한 화면($p)의 팝업을 닫습니다. $p 는 빌드가 자동 주입하므로 $c.win.closePopup($p, popupId) 처럼 넘기면 $p 가 callbackParam 자리로 들어가는 오호출입니다. 팝업 XML 안에서는 $c.win.closePopup(result) 로 충분하며, 수신 메시지의 popupId 는 "다른 팝업의 iframe 메시지"를 거르는 용도로만 씁니다.

2iframe 내부 페이지 (자식 창) — iframe-popup-close-sample.html

iframe 내부에서 팝업을 닫는 이벤트(닫기/확인 버튼 클릭)가 발생할 때 호출할 함수입니다. 이 페이지는 보내는 쪽이라 message 리스너를 두지 않습니다.

/**
 * URL 파라미터에서 popupId 를 가져와 상위 창(Parent Window)으로 닫기 요청을 보낸다.
 * @param {Object} [payload={}] 함께 전달할 추가 데이터 — result 키에 팝업 결과를 담는다
 * @param {string} [targetOrigin=location.origin] 메시지를 수신할 상위 창의 Origin
 */
function sendPopupMessage(payload = {}, targetOrigin = location.origin) {
  // 1. 현재 URL의 쿼리 파라미터에서 popupId 추출
  const popupId = new URLSearchParams(window.location.search).get('popupId');

  // 2. popupId 유효성 검사
  if (!popupId) {
    console.warn('URL 파라미터에서 popupId를 찾을 수 없습니다.');
    return false;
  }

  // 3. 전달할 메시지 데이터 구성
  const messageData = {
    execution: 'closePopup',
    popupId: popupId,
    ...payload
  };

  // 4. 상위 창(Parent Window)으로 메시지 전송
  window.parent.postMessage(messageData, targetOrigin);
  return true;
}

// [확인] — 결과를 실어 닫기 / [취소] — 결과 없이 닫기 (부모의 await 결과는 undefined)
btnOk.addEventListener('click', () => sendPopupMessage({ result: { status: 'OK', value: input.value, closedAt: new Date().toISOString() } }));
btnCancel.addEventListener('click', () => sendPopupMessage());

0호출 화면 XML — SMPIFR10000.xml

값을 돌려주는 팝업 호출은 기존 샘플(ULDFIL52100 → ULDFIL52110)과 같은 await 패턴입니다.

scwin.btn_open_onclick = async function () {
    try {
        const param   = { callerScreenId : scwin.screenId, memo : "호출 화면이 넘긴 값" };
        const options = { id : "SMPIFR10001", popupName : "iframe 팝업", width : 720, height : 560, frameModal : "top", type : "pageFramePopup" };

        const result = await $c.win.openPopup("/ui/sample/template/SMPIFR10001.xml", options, param);

        if ($c.util.isEmpty(result)) { /* 취소 또는 팝업 자체 닫기 */ return; }

        dma_result.set("status", result.status);
        dma_result.set("value", result.value);
    } catch (ex) {
        await $c.exception.handleError(ex, { context : "SMPIFR10000.btn_open_onclick" });
    }
};

3. 핵심 포인트

  • 안전한 데이터 전달: iframe 간 직접적인 스크립트 접근 대신 웹 표준 postMessage API를 사용하여 도메인이 다르더라도(Cross-Origin) 안전하게 통신할 수 있습니다.
  • 유연한 데이터 확충: sendPopupMessage({ result: { … } }) 처럼 payload 를 전달하면 팝업을 닫으면서 결과값이나 처리 상태를 호출 화면까지 한 번에 전달할 수 있습니다.
  • 리스너 생명주기: message 리스너는 window 전역에 붙습니다. WebSquare 는 SPA 라 화면이 바뀌어도 window 가 유지되므로, 등록한 팝업 XML 이 onpageunload 에서 같은 함수 참조로 해제해야 팝업을 열 때마다 리스너가 쌓이지 않습니다.
  • 수신 필터 4단계: 출처 → 데이터 형태 → execution → popupId. WebSquare 엔진도 iframe 클릭·마우스다운·키업 전파용 { _wq_type: … } 객체를 같은 message 채널로 모든 iframe 에 보내므로, 자기 규약의 메시지만 골라내야 합니다.
  • 보안 권장사항: 이 샘플의 iframe 페이지는 같은 출처(/resources/**)라 targetOrigin 과 event.origin 을 location.origin 으로 고정했습니다. 다른 도메인에 두면 양쪽 모두 그 도메인으로 제한합니다.
리스너를 두는 위치 — iframe 을 띄우는 팝업 XML 에 두는 것이 기본입니다(등록한 곳이 해제도 책임). iframe 팝업이 여러 화면에 생기면 $c.win 에 전역 브리지를 만들어 config.xml 최상위 initScript 에서 1회 초기화하고 $p.closePopup(popupId, result) 로 id 지정 닫기를 하는 방식으로 승격합니다. iframe 내부 페이지(보내는 쪽)와 화면마다 실행되는 pageFrame initScript 에는 두지 않습니다.
