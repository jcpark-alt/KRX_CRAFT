WebSquare Submission → executeDynamic Generator

<xf:submission> XML 을 붙여넣으면 $c.sbm.executeDynamic 호출 스크립트를 생성합니다. (ref/target 은 간소화 문법으로 변환)

입력

ref / target 간소화 변환 규칙 (sbm.xml 기준) 
[ref]   요청 DataCollection (data:json,... → 간소화)
  data:json,dma_a                              → dma_a
  data:json,{"id":"dma_a","key":"body"}        → dma_a=body
  data:json,["dma_a","dlt_b"]                  → dma_a,dlt_b

[target] 응답 DataCollection (data:json,... → 간소화)
  data:json,dlt_a                              → dlt_a
  data:json,{"id":"dlt_a","key":"body.content"} → dlt_a=body.content
  data:json,{"action":"append","id":"dlt_a"}    → dlt_a|append    (기존 유지 + 추가)
  data:json,["dlt_a","dlt_b"]                   → dlt_a,dlt_b

· id=key  : 응답 경로 지정 (점(.) 경로 허용, 예: body.content)
· |append : setJSON(data, true) 누적 적재
· method=post / mode=asynchronous / mediatype=application/json 은 기본값이라 생략
