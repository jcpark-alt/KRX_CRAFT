# WebSquare6 공통 검증(Validation) 모듈 기능 추가 및 개선 명세서

본 문서는 WebSquare6 환경에서 공통 검증(Validation) 모듈의 기능 추가, 메시지 포맷 개선 및 옵션 세부화 사항을 정리한 명세서입니다.

---

1. **Focus 이동 옵션 추가 (`focus`)**
   - **1.1 개요**
     - 검증 실패 시 포커스를 이동시킬 컴포넌트의 ID를 별도 옵션(`focus`)으로 지정할 수 있는 기능을 추가합니다.
     - 옵션 값이 존재할 경우, 해당 컴포넌트로 포커스를 자동 이동합니다.
   - **1.2 활용 예시 (분리 입력 및 합산 검증)**
     - *시나리오*: 법인등록번호 입력 시 화면상에서는 입력란이 2개로 분리되어 있고, 실제 DataMap에는 합쳐진 값이 연결되는 경우
     - *화면 컴포넌트 구성*:
       1. `ipt_corpRegNo1`: 법인등록번호 앞자리 (DataMap 미연결, 최대 6자리)
       2. `ipt_corpRegNo2`: 법인등록번호 뒷자리 (DataMap 미연결, 최대 7자리)
       3. `ipt_corpRegNo`: 실제 검증 대상 및 DataMap 연결 컴포넌트 (최대 13자리)
     - *적용 방법*: `ipt_corpRegNo` 검증 실패 시, 사용자 입력 편의를 위해 포커스를 첫 번째 입력란인 `ipt_corpRegNo1`로 지정합니다.
     ```javascript
     // Validation Options 예시
     {
         target: "ipt_corpRegNo",
         focus: "ipt_corpRegNo1", // 검증 실패 시 포커스를 이동할 컴포넌트 ID
         rules: { ... }
     }
     ```

2. **바이트 수 초과(MAXLENGTHB) 메시지 옵션화**
   - **2.1 개요**
     - `MAXLENGTHB` 규칙 위반 시 출력되는 검증 메시지를 옵션을 통해 유연하게 설정할 수 있도록 개선합니다.
   - **2.2 메시지 포맷 규칙**
     1. 기본 바이트 단위 메시지: `${name} 최대 ${val}byte 이하로 입력해주세요.`
     2. 한글/영문 분리 안내 메시지 (옵션 지정 시): `${name} 한글 ${val1}자 영문 ${val2}자 이내로 입력해주세요.`

3. **필수 입력/선택(`required`) 메시지 기본값 자동화**
   - **3.1 개요**
     - `required : true` 옵션 설정 시, 컴포넌트 유형(Type)에 따라 메시지 문구가 자동 분기되어 출력되도록 설정합니다.
   - **3.2 컴포넌트 유형별 출력 문구**
     1. 선택형 컴포넌트 (`radio`, `checkbox`, `selectbox` 등): `${name}을(를) 선택하세요.`
     2. 입력형 및 기타 컴포넌트 (`input`, `textarea` 등): `${name}을(를) 입력하세요.`

4. **컴포넌트 간 값 비교 옵션 추가 (`compare`)**
   - **4.1 개요**
     - 두 개 컴포넌트의 값을 비교하여 서로 동일한지(또는 조건에 맞는지) 검증하는 옵션을 추가합니다.
   - **4.2 기존 로직 예시**
     ```javascript
     if (acntClsMm1.getValue() === acntClsMm2.getValue()) {
         await $c.win.alert("동일한 결산월이 존재합니다.\n결산월을 확인해주세요!");
         acntClsMm2.focus();
         return false;
     }
     ```
   - **4.3 공통 모듈 적용 방식**
     1. `compareTarget`: 비교할 대상 컴포넌트 ID (`acntClsMm2`)
     2. `compareType`: 비교 조건 (예: `"EQUAL"`, `"NOT_EQUAL"`)
     3. `focus`: 검증 실패 시 포커스를 이동할 컴포넌트 지정 (`acntClsMm2`)
     4. `message`: 사용자 정의 출력 메시지

5. **특정 값 확인 및 커스텀 메시지 옵션 추가 (`matchValue` / `message`)**
   - **5.1 개요**
     - 컴포넌트의 항목 값이 특정 값인지(또는 비어 있는지) 확인하고, 실패 시 지정된 커스텀 메시지를 출력하는 옵션을 추가합니다.
   - **5.2 기존 로직 예시**
     ```javascript
     if ($c.util.isEmpty(ipt_newYn.getValue())) {
         await $c.win.alert("아이디 중복확인 여부를 확인하십시오.");
         ipt_integUsrId.focus();
         return false;
     }
     ```
   - **5.3 공통 모듈 적용 방식**
     1. `emptyCheck` / `matchValue`: 특정 조건 또는 미입력 여부 체크
     2. `message`: `"아이디 중복확인 여부를 확인하십시오."`
     3. `focus`: `"ipt_integUsrId"` (실제 포커스가 가야 하는 입력 컴포넌트 지정)

6. **동의/체크(`CHECKED`) 메시지 문구 변경**
   - **6.1 개요**
     - 약관 동의 및 체크박스 검증(`validateKey === "CHECKED"`) 시 미체크 항목에 대해 출력되는 메시지 문구를 다듬어 가독성을 높입니다.
   - **6.2 검증 처리 대상 (FALSE_VALUES)**
     - 미체크 및 false 계열 값 전부 실패 처리 (`""`, `"0"`, `"FALSE"`, `"N"`, `"OFF"`)
   - **6.3 메시지 변경 내용**
     1. 기존: `${name} 체크(동의)해주세요.`
     2. 변경: `${name} 동의 해주세요.`

7. **허용 문자열(`allowChar`) 유형별 메시지 세부화**
   - **7.1 개요**
     - `allowChar` 옵션을 사용하여 허용 문자 조합을 제한하는 경우, 해당 조합 조건에 맞춘 세부 안내 메시지를 출력합니다.
   - **7.2 조합별 메시지 출력 규칙**
     1. 한글: `${val} 한글만 입력이 가능합니다.`
     2. 영문: `${val} 영문만 입력이 가능합니다.`
     3. 숫자: `${val} 숫자만 입력이 가능합니다.`
     4. 영문 + 숫자: `${val} 영문+숫자만 입력이 가능합니다.`
     5. 영문 + 숫자 + 특수문자: `${val} 영문+숫자+특수문자만 입력이 가능합니다.`
