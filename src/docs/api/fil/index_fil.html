업무 공통 함수(fil) $c.fil

fil 업무 모듈(상장공시 필링 — ELW/ETN/디지털/예심/채권)에서 추출한 업무공통(KRX 고유) 함수를 작성한다. 필링 입력화면 전반에서 재사용되는 소수점 허용 콤마 처리(컴포넌트 단위), 처리 확인 가드, 공시 제출 가능 시간대 판정. 분석/트래킹(_trk_*) 함수는 trk.xml($c.trk), 문서 인쇄(Rexpert) 함수는 print.xml($c.print)로 분리. 종목검색·컴포넌트 값 get/set·메시지·로그저장 등 ins 모듈과 동일 사본 함수는 $c.ins 를 재사용한다. 함수명은 camelCase 로 표준화하고 JSDoc 에 AS-IS 원본명을 병기한다.

fil.xml · 7개 메서드

$c.fil.setComma(numstr)

숫자 문자열에 천단위 콤마를 찍는다. (소수점 이하·음수 보존)
(AS-IS: fn_SetComma, origin: digitalNumberFormat.xml)

타입이름설명
Stringnumstr원본 숫자 문자열

반환 String 콤마가 적용된 문자열

var s = $c.fil.setComma("1234567.89"); // "1,234,567.89"

$c.fil.delComma(numstr)

콤마 등 숫자 외 문자를 제거해 정규화된 숫자 문자열로 만든다. (소수점·음수 보존, 선행 0 정리)
(AS-IS: fn_DelComma, origin: digitalNumberFormat.xml)

타입이름설명
Stringnumstr원본 문자열

반환 String 숫자만 남긴 문자열(빈값/`0-` 은 "")

var n = $c.fil.delComma("1,234.50"); // "1234.50"

$c.fil.objSetComma(numObj)

컴포넌트 값에 천단위 콤마를 적용해 다시 설정한다. (선행 '.' 은 '0.' 으로 보정)
(AS-IS: fn_ObjValueSetComma, origin: digitalNumberFormat.xml)

타입이름설명
ObjectnumObj대상 입력 컴포넌트

반환 void 

$c.fil.objSetComma(form["isuPrc"]);

$c.fil.objRmComma(numObj)

컴포넌트 값에서 콤마를 제거해 다시 설정한다.
(AS-IS: fn_ObjValueResetRmComma, origin: digitalNumberFormat.xml)

타입이름설명
ObjectnumObj대상 입력 컴포넌트

반환 void 

$c.fil.objRmComma(form["isuPrc"]);

$c.fil.objRmComma2(numObj)

값이 있을 때만 컴포넌트 콤마를 제거한다. (null/빈값을 0 으로 바꾸지 않는 안전판)
(AS-IS: fn_ObjValueResetRmComma2, origin: digitalNumberFormat.xml)

타입이름설명
ObjectnumObj대상 입력 컴포넌트

반환 void 

$c.fil.objRmComma2(form["isuPrc"]);

$c.fil.confirmProcess(gubun)

처리 구분(저장/수정/삭제/제출)에 맞는 확인 다이얼로그를 띄우고 진행 여부를 반환한다.
(AS-IS: fn_isProcess, origin: digitalApplList.xml)

타입이름설명
Stringgubun처리 구분 (I:저장 U:수정 D:삭제 S:제출)

반환 Boolean 사용자가 확인하면 true, 취소하면 false

if (!$c.fil.confirmProcess("S")) return;

$c.fil.getSubmitGubun(nowDate, beforeLogin, businessClosing)

현재 시각으로 공시 제출 가능 시간대 구분코드를 판정한다. (평일 18:00 마감)
(AS-IS: timeGuBun, origin: currentTime.xml)

타입이름설명
DatenowDate기준 시각(서버시각 권장)
BooleanbeforeLogin로그인 전 화면이면 true (마감 시 3, 아니면 2)
StringbusinessClosing영업마감 여부("Y"=마감 / "N"=개시). 17~18시 외 시간대 판정에 사용

반환 Number 0:제출가능 1:마감30분전 2:제출불가(로그인후) 3:제출불가(로그인전/마감)

var gb = $c.fil.getSubmitGubun(new Date(serverTime), false, "N");
