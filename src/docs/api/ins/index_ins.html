업무 공통 함수(ins) $c.ins

ins 업무 모듈(상장·발행·공시)에서 추출한 업무공통(KRX 고유) 함수를 작성한다. (종목검색, 컴포넌트 값 get/set, 입력검증, 기간·일자, 메시지, 표준코드 매핑, 문자열 Hex, 로그저장). 분석/트래킹(_trk_*) 함수는 trk.xml($c.trk), 문서 인쇄(Rexpert) 함수는 print.xml($c.print)로 분리. 함수명은 camelCase 로 표준화하고 JSDoc 에 AS-IS 원본명을 병기한다.

ins.xml · 20개 메서드
