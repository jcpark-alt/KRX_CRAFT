업무 공통 함수(mgt) $c.mgt

mgt 업무 모듈에서 추출한 업무공통(KRX 고유) 함수를 작성한다. (종목검색, 로그저장, 데이터셋 보조, UI/메시지). 분석/트래킹(trk*) 함수는 trk.xml($c.trk)로 분리. 함수명은 camelCase 로 표준화하고 JSDoc 에 AS-IS 원본명을 병기한다.

mgt.xml · 16개 메서드
