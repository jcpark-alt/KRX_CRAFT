$c.data.getMessage(msgId)

공통 메시지 코드에 해당하는 메시지를 반환합니다. 공통 메시지 정의 파일(common_message.json)을 우선 조회하고, 없으면 서버 다국어 메시지(WebSquareLang)로 폴백합니다.(common_message.json은 최초 호출 시 1회 지연 로드)
메시지 본문에 "$[n]{받침조사/무받침조사}" 형태의 인라인 조사 마커를 쓰면, 해당 인자의 받침 유무에 따라 조사를 자동 선택해 "값+조사"로 치환한다.(한국어 화면에서만 동작, 빈 인자면 마커 유지)

타입이름설명
StringmsgId메시지 ID. 두번째 인자부터는 메시지의 자리표시자($[0], $[1] ...)를 순서대로 치환한다.($[n] ← (n+2)번째 인자)
$c.data.getMessage("MSG_CM_00001");  // "변경된 데이터를 저장하시겠습니까?"
$c.data.getMessage("MSG_CM_00002", $c.str.attachPostposition("전화번호"));  // "전화번호는 필수입력값입니다."
$c.data.getMessage("MSG_CM_00003", "세션이 종료되어");  // "세션이 종료되어 로그인 화면으로 이동하겠습니다."
$c.data.getMessage("MSG_CM_00007", "엑셀", "5M");  // 엑셀 파일의 크기가 5M를 초과 했습니다.

REST API 방식 처리를 위해서 GET Method에 대해서 Request 데이터를 Path Variable 치환 및 QueryString으로 생성한다.

1. Path Variable 처리 : Action에서 "/testJsonMap/{procId}/{seq}/"와 같이 Path Variable(${procId}, ${seq})을 선언할 경우,
해당 변수를 DataMap이나 RequestData(JSON)에 정의된 Key의 Value으로 치환한다.
DataMap이나 RequestData(JSON) 안에 Path Variable({procId}, {seq})에 정의된 procId와 seq Key(Column)이 존재해야 한다.
Key가 존재하지 않을 경우 Path Variable에 추가하지 않는다.
Path Variable에 추가된 Key 값은 GET 방식일 경우 생성되는 QueryString에서 제외 시킨다.

2. QueryString 처리 : GET Method으로 Action을 호출할 경우, 해당 변수를 DataMap이나 RequestData(JSON)에 정의된 Key와 Value으로 치환한다.
DataMap이나 RequestData(JSON) 안에 Path Variable({procId}, {seq})에 정의된 procId와 seq Key(Column)이 존재해야 한다.
단 건 데이터(Map)만 QueryString으로 생성해서 서버에 전송하고, Array 형태의 데이터의 경우에는 QueryString으로 포함시키지 않는다.

$c.sbm.executeDynamic(options, requestData, obj, execOptions)

Submission를 동적으로 생성해서 실행합니다.
options.ref / options.target 은 간소화 문법을 지원한다. DataCollection ID만 콤마(,)로 구분해서 전달하면,
ref는 WebSquare 표준 표현식(data:json,...)으로 변환되어 요청에 사용되고, target은 통신 성공 시 응답 본문(responseJSON.body)을
선언 순서대로 대상 DataCollection에 직접 적재한다. (본문이 배열이면 순차 매핑, 단일 객체면 첫 target) target 항목에 "|append" 를
붙이면 기존 데이터를 유지하며 추가한다(setJSON(data, true)). "data:" 로 시작하는 기존 표현식을 그대로 넘기면 엔진이 직접 바인딩한다.
자세한 규칙은 scwin.__normalizeRefTarget / scwin.__bindResponseToTargets 참고.
options.gridview 를 지정하면 통신 성공 시 refresh 대상 grid에 grid.initGrid()를 호출하고, target DataCollection의 데이터 로드(ondataload) 시 grid.refresh()와 첫 셀 포커스(setFocusedCell(0,0)), 조회된 데이터없음(alert)를 수행한다.
gridview는 콤마(,)로 구분한 다중 ID 문자열("grd_main,grd_sub")을 지원한다. grid별 접미사 옵션으로 실행을 제어한다 : "id|focus"(포커스), "id|refresh"(refresh/initGrid 끔), "id|focus,refresh"(포커스+refresh호출), "id|focus,refresh,message"(셋 다 옵션실행). 옵션 미지정 시 refresh + fous미지정 + message 모두 실행한다.

// 전체 옵션 예시 — 동작 옵션 4종 + 규칙 종류별 지정 예
const options = {
validateType : "alert",  // alert(알림) | mark(req 클래스 마킹) | all(알림+마킹). 기본 alert
checkType    : "single", // single(첫 실패 즉시 중단·개별 알림) | multi(전건 수집 후 취합 알림). 기본 single
focus        : true,     // 실패 항목 포커스 이동 여부. 기본 true
editMode     : true,     // (그리드) 실패 셀 포커스 시 편집모드 진입 여부. 기본 true
fields : {
// 기본 규칙 — 필수/문자/길이
ipbName    : { required : true, maxLength : 10, name : "사원명" },
ipbAge     : { required : true, num : "n", fromNum : 1, toNum : 150, name : "나이" },
ipbCode    : { allowChar : "0-9A-Z", ignoreChar : "#", fixLength : 8, name : "코드" },
ipbRemark  : { minLength : 5, maxLength : 100, name : "비고" },

// byte·자릿수 규칙 — 한/영 혼합 byte 제한, 정수.소수 자리수
ipbCorpNm  : { required : true, maxLengthB : 80, name : "발행기관명" },      // 한글 40자/영문 80자
ipbRate    : { num : "f", maxLengthF : "10.2", name : "수수료율" },          // 정수 10자리.소수 2자리

// format 규칙 — email/phone/mobilePhone/date/birth/securityNumber/bizNum/corpNum/urlNoProtocol
ipbEmail   : { required : true, format : "email", name : "이메일" },
ipbBizNo   : { format : "bizNum", name : "사업자등록번호" },                 // 10자리+검증번호
ipbCorpNo  : { format : "corpNum", name : "법인등록번호" },                  // 13자리+검증번호
ipbHomeUrl : { format : "urlNoProtocol", name : "홈페이지" },                // http:// 등 포함 금지

// 조건부 규칙 — 참조 컴포넌트 값으로 판정 (equals|notEquals|in|notEmpty, message 재정의 가능)
ipbZipCd   : { emptyIf : { compID : "sbx_nation", notEquals : "410",
message : "외국국적은 우편번호를 입력할 수 없습니다." }, name : "우편번호" },
calChgDt1  : { requiredIf : { compID : "ipb_chgNm2", notEmpty : true,
message : "상호변경내역1 변경일을 먼저 입력해주세요." }, name : "변경일1" },

// 그룹 중복·체크박스 규칙
sbxMonth1  : { duplicateGroup : "settleMonth", name : "결산월1" },           // 같은 그룹명 간 중복 금지
sbxMonth2  : { duplicateGroup : "settleMonth", name : "결산월2" },
chkAgree   : { checked : true, name : "개인정보 처리방침 동의" }             // 미체크("0"·false 포함) 실패
}
