규칙 값 안내 (validateDataCollect JSDoc 기준) 
required     : 필수 입력            allowChar  : "0-9"(정수) · "0-9."(실수) · "a-zA-Z"
ignoreChar   : 입력 불가 문자        min/maxLength : 최소/최대 문자수
num          : n(숫자)·i(정수)·f(실수)
format       : email·date·phone·mobilePhone·securityNumber·bizNum·corpNum·urlNoProtocol·birth
fromNum/toNum: 최소/최대 입력 숫자   checked : 체크박스 필수 체크(약관 동의 — "0"/false 도 실패)
[고급] fixLength(고정 문자수) · min/maxLengthB(byte) · maxLengthF("10.2" 정수+소수 자릿수)
[고급] emptyIf/requiredIf : 조건 객체를 원문으로 입력 — { compID : "sbx_nation", notEquals : "410", message : "..." }
       (equals|notEquals|in|notEmpty 로 참조 컴포넌트 값을 판정해 입력 금지/필수 처리)
[고급] duplicate : (그리드) 컬럼 값 행 간 중복 금지 · duplicateGroup : (폼) 같은 그룹명 필드 간 중복 금지
※ required·checked 외 규칙은 빈 값을 통과시킴(필수 항목은 required 병행 지정)
※ gridView 는 입력 허용문자/자릿수 등을 Column 속성으로도 설정 가능 — 본 도구의 options 와 병행 시 중복 주의
